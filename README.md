# Arca Interiors

Interior design studio website — Astro, static build.

## Run locally
```
npm install
npm run dev
```

## Build
```
npm run build
```

## Pages
- `/` — home
- `/studio` — the duet, philosophy, how we work, services
- `/portfolio` — selected work
- `/contact` — contact form

## Images
Drop photos into `public/images/`:
- `hero.jpg` — homepage featured (light, airy, natural light)
- `project-1.jpg` … `project-3.jpg` — portfolio covers

## Brand
- Background: warm off-white `#faf8f3`
- Accent: blue `#3a6ea5` — used sparingly
- Fonts: Libre Caslon Text (headings), Syne (logo), Archivo (body)
